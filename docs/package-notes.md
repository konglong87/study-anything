# Package Notes

`study-anything` is a standalone public skill package for learning conversations.

The package deliberately avoids:

- product-specific names and private workspace assumptions;
- provider, database, or deployment dependencies;
- request-time execution of package scripts;
- storing learner content in files as part of a response;
- claims about persistence or mastery that the host has not confirmed.

The package contains two operating surfaces:

- `SKILL.md` gives the complete behavior guide;
- `runtime.md` gives a concise prompt for hosts that provide structured context.

The examples are illustrative inputs and expectations. They are not tied to any particular application or account.
